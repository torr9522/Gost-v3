# 菜单树

## 主菜单

- `1` 安装 gost v3
- `2` 更新 gost
- `3` 卸载 gost
- `4` 启动 gost
- `5` 停止 gost
- `6` 重启 gost
- `7` 新增 gost 转发配置
- `8` 查看现有 gost 规则
- `9` 删除一则 gost 规则
- `10` gost 定时重启配置
- `11` 自定义 TLS 证书配置

## 7. 新增 gost 转发配置

- `1` tcp+udp 流量转发，不加密
- `2` 加密隧道流量转发
  - `1` tls
  - `2` ws
  - `3` wss
- `3` 解密由 gost 传输而来的流量并转发
  - `1` tls
  - `2` ws
  - `3` wss
- `4` 代理服务
  - `1` shadowsocks
  - `2` socks5
    - `1` 添加代理
      - `1` 无认证
      - `2` 有认证
    - `2` 管理代理
  - `3` http
    - `1` 添加代理
      - `1` 无认证
      - `2` 有认证
    - `2` 管理代理
  - `4` https
    - `1` 添加代理
      - `1` 无认证
      - `2` 有认证
      - 证书模式：
        - `1` 自动申请域名证书
        - `2` 自动申请 IP 证书
        - `3` 使用已有证书
    - `2` 管理代理
      - `1` 删除代理
      - `2` 重新申请证书
      - `3` 返回
- `5` 多落地均衡负载
  - `1` 不加密
  - `2` tls
  - `3` ws
  - `4` wss
- `6` 转发 CDN 自选节点
  - `1` 不加密
  - `2` ws
  - `3` wss

## 11. 自定义 TLS 证书配置

- `1` 自动申请域名证书
- `2` 自动申请 IP 证书（Let’s Encrypt shortlived）
- `3` 手动上传证书
